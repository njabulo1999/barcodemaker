Help & Documentation

Quick Start Guide

  1. Enter barcode value or SKU in the Basic tab
  2. Adjust layout settings as needed
  3. Click "Generate" to create barcodes
  4. Use "Print" to print or "Export" to save files

Batch Processing

Use CSV format for multiple products:

SKU,Barcode,Product Name,Description,Price

Keyboard Shortcuts

  • Ctrl+G - Generate barcode
  • Ctrl+P - Print
  • Ctrl+E - Export
  • Ctrl+C - Clear all
